# 功能说明与使用边界

AiteEcho（艾特回声）是面向自托管场景的QQ AI助手。当前维护版本由ilovvveu主导，基于上游代码进行了大量新增、重构与部署适配；来源和具体范围见[改动说明](derivative-changes.md)，授权见[LICENSE](../LICENSE)。

本文以当前源码及配置为准，不把“有测试”“已启用”和“真实客户端已验收”混为一谈。下文默认值指发行示例或明确标注的代码默认，不代表任何个人在线实例。

## 1. 接入与模型请求

- 通过NapCat等OneBot 11实现连接QQ，支持反向/正向WebSocket。仓库不分发QQ客户端、账号或NapCat程序，不以QQ官方机器人开放平台适配器自居。
- 推荐AI_BACKEND=direct：独立Node进程请求兼容Responses的API，无需桌面Codex、CLI登录或官方账户额度；仍依赖系统、QQ/OneBot、网络和选定服务可用。任意Chat Completions接口不能直接视为兼容。
- API地址、密钥、模型和low/medium/high强度自行配置；模型无默认个人选择，推理强度默认medium。语音另用独立TTS密钥，不与聊天模型共用账单。
- 可选ACP后端保留，用于操作者选择的ACP agent。其权限、工具和会话机制与direct不同，不自动继承桌面Codex的聊天记忆、MCP、Skills或插件。
- direct非流式获取完整最终答案后发QQ，不把推理过程刷入群聊，不保存或回传上一轮reasoning密文/previous_response_id。对最终答案、响应完整性及发送回执分别校验。

## 2. 群聊、私聊与权限

群聊和私聊默认关闭。先指定ONEBOT_OWNER_USERS、允许用户/群及聊天开关，再按需要开放；主人名单不从普通用户白名单推断。真实结构化@与文字中写出的@/CQ字符串不同，后者不构成触发授权。

| 身份/策略 | 能力与边界 |
| --- | --- |
| 机器人主人 | 显式配置的管理身份，可在对应会话使用/style、/context，在目标群使用/member；不因称呼、人设或模型文字授予权限 |
| QQ群主/管理员 | 根据OneBot返回的同群身份识别；不是机器人主人，不自动获得全局设置权 |
| 普通成员 | 在允许群真实@后按策略提问；可配置allowAllMembers，仅对该群绕过普通用户白名单，不开放其他群或陌生私聊 |
| 特殊成员 | 每群逐人标签、限额或暂停回复；支持单人规则，不是QQ群禁言/踢人 |

开放群的/reset、/prompt、/quiet、/progress、/verbose、/member等设置操作仅主人可用；/style、/context独立要求主人。未开放全员的白名单会话沿用既有会话控制，不能将其称为完整多租户RBAC。普通群成员/status只看公开状态及自身额度，不返回完整内部状态。

普通回复按每人每群滚动60秒限频，replyLimits可分别设置管理员与普通成员额度；开放群未配置时兼容默认管理5次、普通1次。主人普通回复不受分钟限制；特殊规则可覆盖非主人限额，0表示该特殊普通额度不限。已接受但后续失败的请求仍计次，拒绝不会延长冷却；多段QQ答案仍按一轮请求计数。计数和部分角色缓存在进程内，不能作为跨实例共享限额。

## 3. 图片、引用与文档

| 能力 | 支持内容 | 开关/条件与限制 |
| --- | --- | --- |
| 图片输入 | PNG/JPEG/GIF/WebP，单轮多图，模型视觉分析 | 模型/提供方须实际支持图像；默认最多3图、每图6MiB，验签及来源检查，不能用HTTP200代替识图验收 |
| Vision OCR | macOS系统Vision提取图片文字 | ACP_LOCAL_VISION_OCR显式启用，可编译Swift helper；不是Linux/Windows通用OCR，也不等于完整视觉理解 |
| 本地缓存图片 | 受控读取NapCat temp/cache中的实际图片 | ONEBOT_INBOUND_IMAGE_LOCAL_ROOTS默认空；不开放任意磁盘路径，拒绝软链接逃逸和超限文件 |
| OneBot图片流 | 通过已有已认证WS读缓存图片 | 默认关闭；须由get_msg证明属于当前消息/一层引用，不用文字CQ授权，不因Fake-IP而放宽私网规则 |
| 引用消息 | 一层同群/同私聊的正文、图片和文档 | ONEBOT_RESOLVE_REPLIES默认关闭；跨会话拒绝，不执行引用里的命令，不递归扫完整消息树 |
| 文档读取 | PDF文字层、DOCX正文/表格、XLSX单元格/公式原文及TXT/MD/CSV/TSV/JSON/LOG | ACP_READ_DOCUMENTS默认关闭；Python及解析依赖，默认每轮2件、每件10MiB、附件节选共20000字符，后端还会施加全输入预算 |

不支持旧DOC/XLS、加密PDF、扫描PDF页的自动OCR、Office宏执行或复杂版式还原；不把附件图片、批注等未解析内容冒充已读。解析器限制压缩展开、页/表/行列、输出、并发和时限；失败/截断明确标注，不能视为可执行文件沙箱或完整恶意文档检测。

## 4. 联网与按人分析近期发言

开启ACP_WEB_SEARCH后可使用/search或自然语言搜索。direct只调用接口提供的hosted web_search，不附带通用浏览器遥控工具；是否有实时搜索、图像理解及其费用由提供方实际能力决定。来源显示可设on_request/always/never，默认不主动附网页链接；这是展示规则，不是关闭核实或证明答案无误。

ONEBOT_READ_GROUP_HISTORY默认关闭。开启后可在允许群真实@并请求：

- 分析 @成员 最近20条发言。
- 看看 @成员 最近几条消息（“几条”按5条）。
- 分析 @成员 刚刚发言（近10分钟、默认最多10条）。
- /history @成员 20 总结主要观点，或指定今天、昨天、24h、7d。

目标须明确且唯一；引用可用于确定同群发言人，不任意猜人。默认7天/20条，最多1人50条；最多扫描10页/500条群消息，10秒有界读取。扫描上限不是“必然取全目标历史”，撤回/服务未返回内容也不保证可取回。仅分析实际文字样本，媒体只占位，不递归下载，不后台建立全群聊天数据库；所选样本仍会送模型，不能称为零留存。

## 5. 短期上下文与风格

发行示例启用有界本地上下文：最多100次成功问答、24小时或120000序列化字符，先达到者淘汰最旧项。启动、发送前及后台定期修剪，不调用额外摘要模型。/reset清当前会话，不是全局数据删除命令。

direct默认不自动带旧问答；主人/context on后从近期候选选择相关历史，最多6轮/3000历史字符，可能少于6轮或为0。全输入文字还受默认10000字符/20000 UTF-8字节合计限制；图片、工具/搜索内部材料及提供方自加内容不等同于该本地文字预算，不承诺精确账单上限。

群内是一份共享会话，私聊各自隔离；不承诺同群成员之间的长期事实完全隔离。风格不当事实依据，旧助手口吻不作为新风格示范；相关旧答案可能用短节选。默认保留本地问答不等于每次全部上传。

全局instructions与default预设为空白，无固定性别、角色、关系或音色。可选43套模板、主人/style按会话切换，或自行添加UTF-8文本。BOT_REPLY_RULES_FILE控制全局表达与链接展示，每轮热加载；每轮只把选中的一套风格加入模型输入，不上传整个库。风格选择与短期上下文分离，/reset和正常重启不会抹掉风格选择。预设是模型指导，不保证每句话严格一致，更不提升操作权限。

## 6. 命令语音与用量保护

- /语音或/voice只影响这一轮。授权群另启用BOT_VOICE_GROUP_ENABLED后，答案不超过BOT_VOICE_GROUP_MAX_CHARS（默认50个Unicode码点）仅发语音，否则只发完整文字，不截短配音。模型/TTS/转码或QQ发送失败按对应规则处理，群语音失败可退回文字。
- 主人私聊语音先发完整文字，再配短语音；/朗读或/tts仅主人私聊，直接朗读给定文字，不问模型或写入问答历史。普通聊天不自动配音，不开放群友克隆音色。
- 群语音独立滚动60秒，默认成员1条、管理/群主2条、主人不限，三档可配。成功语音也占普通请求额度，语音额满而普通额未满时只发文字；主人不限分钟次数不绕过总预算/单并发/余额。
- ElevenLabs模型、允许的voiceId、稳定度及neutral/lively可配，未预选声音；音色与/style独立。全进程默认单并发、每日2000字符、30秒合成截止及大小保护；私聊新合成另有30秒间隔，失败不自动重试付费合成。
- FFmpeg与silk-wasm本地将音频转Tencent SILK，不等于本地生成语音；TTS仍是外部云服务。账号/模型/音色支持、价格、效果及手机播放须分别验证。

## 7. 诊断、可靠性与运维

direct默认连接10秒、首正文90秒、API阶段总计120秒，最多1次有界重试。只对允许的提交前瞬时错误或明确HTTP429/5xx重试；POST提交后结果不明、断裂响应等不盲目重放，不能保证失败不收费。排队、附件处理和QQ发送各有独立时限，120秒不是端到端SLA。

模型输入预算、DNS/TCP/TLS、提交/响应完整性、模型最终答案、QQ回执、TTS/转码及本地持久化用同轮correlationId区分。诊断只记受控元数据，不记完整请求、正文、密钥或原始上游错误；本地输出/存储异常也不能被误写为接口故障。元数据可能包含运行/会话标识，不应原样公开。

管理HTTP默认回环；配置BOT_ADMIN_TOKEN后/status、/metrics要求Bearer头，非回环强制独立强token。/healthz只看进程，/readyz只看QQ连接，不证明AI可用。默认file store，可选Redis/Postgres；换存储不自动获得分布式去重/限频。Docker与CI提供配置及烟测，实际镜像和跨平台范围见验收说明。

## 数据去向与留存

| 数据 | 可能去向 | 留存/删除边界 |
| --- | --- | --- |
| 当前问题、图片、文档/OCR/引用节选、主动历史分析样本 | 配置的模型服务；必要时其搜索服务 | 提供方规则另行审查，store=false不保证云端零留存 |
| 选中的近期问答 | 开启携带时送模型；本地session store | 有界修剪；关闭携带不等于删除本地记录 |
| 风格/规则、特殊成员设置 | 本地配置/状态；当轮生效部分进入模型输入 | 与聊天上下文分别持久化，不应放密钥 |
| 本轮待配音文字 | 启用的ElevenLabs服务；短时RAM音频缓存 | 不发完整系统/聊天历史；云端按提供方规则 |
| 诊断元数据 | 本地日志/管理指标 | 独立诊断文件默认关闭；启用后有大小轮转，普通stdout由部署者管理 |
| 真实@提问、当时昵称/账号/群、时间、回复与发送状态 | 显式启用的本地独立JSONL存档 | 不自动清理、不回灌模型、不跟随/reset，不自动同步QQ撤回 |
| QQ原生消息/缓存/第三方服务记录 | QQ/OneBot实现及各提供方 | 不受本项目/reset控制，不声称可一键全部清除 |

## 常用命令速查

群聊是否要求@、主体权限与限频均先由配置/代码检查，模型不能自行授权。

| 命令 | 用途与条件 |
| --- | --- |
| /help、/ping、/status | 本地帮助/存活/状态，不调用模型；仍受准入及普通限频 |
| /style list、/style 名称、/style default | 主人查看/切换当前会话预设，default空白 |
| /context on、off、default | 主人在direct会话设置近期问答携带 |
| /reset、/quiet、/progress、/verbose、/prompt | 会话清理/表达/进度/提示预览；开放群仅主人，非全局配置编辑器 |
| /member QQ号 limit 次数、block、label、clear | 主人在目标群设置特殊规则，不执行QQ原生处罚 |
| /search 关键词、/history 对象 范围 | 须开启对应能力，数据范围及来源展示受原规则限制 |
| /语音 问题、/voice 问题 | 显式单轮配音，依群/私聊策略及双重限额 |
| /朗读 文字、/tts 文字 | 仅主人私聊直接朗读，不调用聊天模型 |
