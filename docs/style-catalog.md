# 回复风格目录

共43套（含空白default与原自然风格），通过本人账号在群内@机器人后切换。私聊无需@；选择只影响当前群或当前私聊。其他群友可以提出需求，只有主人能够执行持久化切换。

| 类别 | 可用风格 |
| --- | --- |
| 基础表达 | default（空白）、自然、极简、严谨 |
| 二次元与性格 | 萝莉、御姐、傲娇、猫娘、元气、软萌、高冷、三无、天然呆、腹黑、小恶魔、病娇、邻家姐姐 |
| 服务与陪聊 | 女仆、执事、管家、客服、树洞、佛系 |
| 群聊整活 | 热血、中二、段子手、吐槽、毒舌、捧哏 |
| 古风与叙事 | 古风、文言、吟游诗人 |
| 分析与学习 | 军师、侦探、程序员、老师、苏格拉底、哲学家 |
| 科技语调 | 赛博、机械 |
| 方言 | 东北老铁、四川话、粤语 |

## 使用

- `/style list`：查看可用预设和当前选择。
- `/style 傲娇`、`/style 御姐`、`/style 萝莉`：使用对应风格名切换。
- `/style show`：查看当前预设的完整要求。
- `/style default`：恢复空白，不额外指定表达风格。

预设均为短文本，主要描述语气、句式、口头禅的使用分寸；每次仅加载当前选择的一份。群聊日常可选自然/元气/段子手，认真讨论可选严谨/军师，轻松角色口吻可选傲娇/御姐/猫娘。病娇采用轻度悬疑戏剧感，毒舌只评价事情与观点，不对群友作人身攻击。

源模板为`examples/styles/*.txt`，当前运行目录为`config/styles/*.txt`。新增或修改文件后下次命令/回复即可读取，不需要重启；不自动改变已经保存的选择。空白default文件保持0字节，切换不调用模型，实际风格表现由当前模型生成。

所有风格另受独立`config/reply-rules.json`全局表达规则控制，包括默认不主动附来源链接、旧助手语气不作为当前风格示例。空白default仍为空文件，但不绕过全局规则。2026-10-23邻家姐姐已补接梗、避免短句训诫及温暖克制回应示好的示例，保留原历史与选择；详见[全局回复规则](configuration.md#全局回复规则)。

角色分类参考：[Hersona](https://github.com/shiro-0x/hersona)的性格、语气与角色属性设计。本批中文预设由本项目重新编写，适配现有短提示词与本地切换机制。
