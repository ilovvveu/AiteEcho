# AiteEcho 使用教程

安装与连接请按 [快速开始](getting-started.md)。默认主线是独立API，ACP为兼容后端，不要混用两套凭据或把QQ在线当模型健康。

常用命令：/help、/ping、/status、/reset；/style list 和 /style default 由主人控制；/search 显式搜索；可选 /语音 或 /voice 触发单次语音。群内均遵循真实@与权限检查。

群规则允许全员@，但不同身份的回复频率、语音频率和逐人特殊标记独立控制。文件示例不包含真实群号和主人；请自行配置。/reset清短期上下文，不清@存档、语音配额或风格选择。

图片、引用和文档只读取经校验且属于当前会话的内容；缺失、超限、格式不支持会标注。文本风格不更改声线、不授予权限。不要让群成员向机器人发送密码、令牌或应保密的个人资料。
